# 08-02 RAG迭代的关键：评估

[0:00] 这一小节我们来了解一下RAG评估的标准
[0:03] 也就是我们要从哪些角度来评估一个RAG系统
[0:08] 我们先来回顾一下简单的RAG的流程
[0:11] 首先,用户提出个问题
[0:14] 根据这个问题去检索上下文的信息
[0:17] 然后结合这些上下文信息
[0:20] 大远模型来生成问题的答案
[0:22] 简单的可以概括为一个问题,一个上下文,一个答案
[0:26] RAG评估就是通过衡量这三者之间的相关
[0:30] 程度以此来评估RAG系统效果的好法
[0:34] 具体的评估标准总共有三个
[0:42] 第一个是在问题和检索的上下文之间
[0:45] 需要评估上下文的相关性
[0:49] 也就是系统检索到的上下文信息
[0:52] 是否紧密围绕用户提出的问题来展开
[0:55] 是否包含了解答这个问题所需要的关键信息
[1:00] 换句话说,这个指标就是评估上下文的一个可靠性
[1:04] 第二个是在检索的上下文信息和生成的答案之间
[1:09] 我们需要评估生成的答案和给定的上下文
[1:14] 是否存在事实的一致性
[1:16] 换句话说,就是生成的答案能不能通过
[1:20] 这个给定的上下文信息来推断出来
[1:23] 而不是胡说八道
[1:25] 这个就是忠实性的一个标准
[1:30] 第三个是生成的答案和问题之间
[1:33] 需要去评估答案的一个相关性
[1:36] 也就是判断答案是否直接回答了用户提出的问题
[1:42] 当然同时还要考虑回答的答案是否完整
[1:45] 有没有遗漏
[1:46] 另一方面也要考虑回答的答案
[1:49] 有没有包含一些不相关的冗余的信息
[1:53] 这个就是IG评估的三大标准
[1:57] 包括上下文的相关性
[2:00] 忠实性以及回答的相关性
[2:04] 接下来我们通过这个例子来说明一下这三个标准
[2:08] 我们来看一下这边给定的上下文和它生成的答案
[2:13] 很明显这个答案和提供的上下文信息里面的事实是一致的
[2:19] 也就是说苹果成立于1976年
[2:21] 这个信息是可以在上面提供的上下文的信息里面
[2:26] 找到相关的一些依据
[2:28] 也就是满足忠实性的标准
[2:31] 然后是答案的相关性标准
[2:34] 很明显第一个答案和问题是相关的
[2:37] 而第二个答案和问题是不相关的
[2:41] 第三个是上下文的相关性
[2:44] 我们给出一个问题
[2:47] 然后给出两个不同的上下文信息
[2:52] 从这两个上下文信息的内容我们就可以得出
[2:57] 第一个上下文信息和问题是相关的
[3:01] 也就是说这个上下文信息不能为回答这个问题提供有价值的信息
[3:07] 比如苹果发布了iPhone这个上下文
[3:10] 它并没有提供苹果公司成立的一些信息
[3:14] 所以这个上下文和这个问题是不相关的
[3:18] 从上面的例子中我们也可以看出要进行IG系统评估
[3:24] 我们就要去判断很多的一个相关性的信息
[3:28] 而相关性的信息需要一定的语意的理解
[3:32] 所以在有的时候人为的评估也是IG评估的一个重要的手段
[3:37] 相对来说人为的评估更加准确
[3:39] 当然它也更加耗时
[3:42] 成本也比较高
[3:43] 除了人为评估以外
[3:44] 大远模型它也有很强的语意理解
[3:47] 所以现在有很多借助大远模型的能力进行IG的评估
