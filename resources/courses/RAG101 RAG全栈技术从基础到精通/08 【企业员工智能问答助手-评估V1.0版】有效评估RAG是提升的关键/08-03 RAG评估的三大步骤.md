# 08-03 RAG评估的三大步骤

[0:00] 在确定了RAG评估的标准之后,要完成一个RAG系统的评估,我们需要三个大的步骤。
[0:07] 接下来我们来详细分析一下这三个步骤。
[0:11] 第一个步骤是需要构建一个评估RAG系统的测试数据集,也就是说我们需要在哪个数据上去评估RAG的系统。
[0:20] 这个数据通常包括你要提出的问题以及这个问题的一个标准的答案。
[0:26] 第二个步骤是确定评估的指标,通常就是我们上面讲过的RAG评估标准里面的一些指标,或者是一个标准下衍生出来的多个指标。
[0:38] 有了数据,有了指标以后,我们就要进行RAG评估的执行。
[0:44] 整个评估的过程就是将测试数据集输入到RAG系统中。
[0:50] 然后评估系统会收集这些上下文信息和生成的答案来计算指标的数值。
[0:57] 这个就是整个RAG评估的一个过程。
[1:00] 这个过程的一个重点就是如何计算这些指标的一个数值。
