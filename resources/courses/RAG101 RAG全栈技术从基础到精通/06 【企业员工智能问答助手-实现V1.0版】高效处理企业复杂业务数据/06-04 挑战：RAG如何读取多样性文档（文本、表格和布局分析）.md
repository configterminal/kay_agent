# 06-04 挑战：RAG如何读取多样性文档（文本、表格和布局分析）

[0:00] 这一小节中,我们来介绍一下不同文档的解析方法。
[0:04] 不同的文档因为格式不同,而需要不同的解析方法。
[0:09] 好消息是像LaneChain和Lama Index这样的AI硬框架对常用的文档解析做了整合封装。
[0:17] 所以在这一小节中,我们就用LaneChain的Document Loaders来讲解一下这些方法。
[0:24] 当然我们也会顺便讲解一下其他酷的一些解析方法。
[0:29] 方便后续做定制化的开发。
[0:32] 上面列的这些酷,后面都会详细做一些讲解。
[0:44] 第一个文档格式是HTML,它是创建网页的标准标记语言。
[0:51] HTML内容可以包括文本、图片、视频和音频等等。
[1:04] 这些内容都放在不同的标记里面,然后通过浏览器进行渲染。
[1:10] HTML解析主要是通过识别这些标记符号去获取里面的内容。
[1:17] 在LaneChain中有很多方法可以运来解析HTML,其中一个就是Web Based Loader。
[1:25] Web Based Loader会先用URLib来下载HTML文件,然后通过Beautiful Sub来解析其中的内容。
[1:36] Web Based Loader是包含在Document Loaders这个包里面的。
[1:40] 另外一个,如果是本地的HTML文件,可以直接通过BSHTMLoader来进行解析。
[1:52] BSHTMLoader其实就是通过Beautiful Sub解析HTML的内容。
[2:00] 当然需要注意的是,这里不管是Web Based Loader还是BSHTMLoader,
[2:07] 对于HTML的解析都是直接将所有的标记里面的内容按顺序的拼接在一起。
[2:14] 当然它会用一个放行符进行分割。
[2:17] 它没有考虑HTML中特殊的一些内容,比如说代码块。
[2:23] 这是比较通用的解析,如果说要做一些特殊的解析,就要做定制化的一些开发。
[2:30] 如果要定制化的开发,就需要你对文档结构有一定的了解。
[2:36] 比如这个HTML的页面,前面是一个代码块,对应到原码里面的标记语言是在这个DIV下面。
[2:47] 有了这些了解以后,我们就可以通过Beautiful Sub来进行定制解析。
[2:55] Beautiful Sub可以通过标记语言和CSS样例来提取HTML中的内容。
[3:03] 比如这个例子中,就可以通过指定的标签和CSS类名通过Find All来提取所有Highlight样式的内容。
[3:13] 通过这个方法就可以提取到HTML中所有高量代码的部分。
[3:19] 然后是PDF文档,PDF是Adobe公司开发的一个文件格式,它现在是一个开发的标准。
[3:31] 只要你遵循标准里面的指令,就可以读取PDF的内容。
[3:38] 像这里就是PDF里面的一些指令。
[3:41] 因为它是一个开发的标准,所以市面上有很多PDF的阅录器。
[3:47] Lanxian里面也集成了对PDF读取的不同的解析器。
[3:52] 虽然PDF文件很容易读取展示,但是自动精准的识别PDF中的内容还是有一定的挑战性的。
[4:01] 就是我们前面提到过的PDF文件内容的一个复杂性。
[4:06] 比如说PDF里面有一些表格、公式以及不同的版面、识别等等。
[4:12] 这里推荐PyMuPDF,它的特点是可以识别版面以及能够提取PDF文件中的表格和图片信息等等。
[4:22] 在Lanxian中可以通过PyMuPDFloader来解析PDF中的文本和图片。
[4:29] 但是PyMuPDFloader它并没有提供提取表格信息的方法。
[4:35] 当然你也可以直接通过PyMuPDF来直接对PDF文档进行解析。
[4:41] 这样就可以灵活的提取你需要的一些信息,特别是表格信息。
[4:46] 需要注意的是PyMuPDF中它是通过FIDG来读取PDF文档,并通过GetTest和FileTables来读取文本和表格。
[4:58] 而且表格信息可以很方便的转换为Pandas的DataFrame格式,这样就可以很方便的处理表格信息。
[5:05] 当然除了PyMuPDF以外,还有一些利用机器视觉的方式来处理PDF文档。
[5:13] 这些方法可以更加智能的提取PDF文件中的布局信息和表格内容等等。
[5:19] 比如开源的有百度飞江的PPStructure,以及上海人工智能实验室的MadeU,还有后面会详细讲到的RAGFlow。
[5:29] 当然还有一些Sofi的软件,像PDFLux,还有LamaIndex中的LamaPass。这些方法大家如果需要的话可以关注一下。
[5:40] 对于其他的文件格式,比如说Markdown, XML, TST, JSON等等,可以通过一个叫unstructured的库来统一进行解析。
[5:52] unstructured可以通过识别文件的格式来调运不同的解析器,来对文档进行解析。
[6:00] 对于Office文档,Ranchain也集成了相应的方法。
[6:04] Excel可以采用Excel Loader,PPT可以采用PowerPoint Loader。这两个方法背后都是采用unstructured来进行解析。
[6:14] 而Word是采用Dux2 TST Loader,它背后使用的库是Dux2 TST。
[6:21] 当然这些方法都只能提取文本信息。
[6:25] 如果说有更多的定制化的需求,特别是提取表格或者图片的信息,可以采用其他的库进行解析。
[6:34] 比如说Excel这边可以采用Open PY XL,PPT可以采用Python PPTS,Word可以采用Python Dux。
[6:44] 这些库都提供了很多灵活的一些方法,比如Open PY XL可以识别到Excel表格中的合并单元格信息等等。
[6:54] Python PPTS以及Python Dux可以提取PPT和Word中的图片跟表格。
[7:01] 使用这些方法可以更加灵活的读取Office文档中的特定内容进行定制化的开发。
[7:08] 上面讲的都是LangChain中对于一些文档解析方法的分装。
[7:13] 接下来介绍一个最近比较火的RAG文档解析的一个库,叫RAG Flow。
[7:19] RAG Flow中负责文档解析的是Deep DOC,它的特点是基于机器视觉的方式来处理文档。
[7:27] 首先它会将PDF文档转换成图片,然后用OCR来识别图片中的文字,
[7:35] 并利用布局识别模型来识别PDF文档中的布局结构,比如说标题、段落、表格和图像等等。
[7:45] 然后对于识别到的表格内容,Deep DOC会采用TSR的模型进行表格内容的识别解析,
[7:53] 它能够解析出表格中的行列以及合并单元格。
[7:58] 识别到这些内容以后,Deep DOC就会对这些内容进行整合,然后进行文档的解析。
[8:07] 除了PDF以外,Deep DOC它也支持像Word,ECL,PPT,HTML,TXT,MACDAO等多组文档的格式的解析。
[8:17] 我们来看一下具体的一个效果。
[8:20] 首先是OCR文本识别,我们可以通过这个OCR的一个脚本来对文档中的文本进行检测并识别。
[8:28] 然后是布局的识别,可以通过这个脚本对PDF中的布局信息进行识别。
[8:35] 比如说可以识别出文本、公式、表格。
[8:39] 最后是表格解析识别,在识别出表格内容以后,同样也可以通过这个脚本指定TSR的方式对表格内容进行解析。
[8:49] 上面说过它可以解析行列以及合并单元格的一些信息。
[8:54] Deep DOC是目前对PDF文档进行解析比较好的一个开源方法。
[9:00] 当然上面所有的方法都可能不是完美的。
[9:04] 在实际项目中要选择合适的文档解析方法,并有可能要做一些定制化的开发。
