# 课程作用域 — 对话样例（方案验收）

> 对应设计：[course-scope.md](course-scope.md)  
> 目的：用对话核对「临时聊不锁课 + 代指看近窗上下文」是否符合预期  
> 最后更新：2026-07-21  
> 状态：样例已确认；作用域逻辑已落地，单测通过  

说明：

- **本轮作用域**：该轮检索应带的 `course_id`（空 = Open 全库）
- **TurnHint**：仅本轮提示，不永久锁死
- **代指 / 代称**：学员只用「那个 / 这个 / 详细点 / 继续 / 刚才说的」等，**字面不含课名**；所指课程完全靠近窗上下文解析，且**同一代称在不同轮可指向不同课**

## 一、同课指代

### 样例 1：同课「详细点」（不应串到职业课）

| 轮 | 学员 | 期望本轮作用域 | 说明 |
|----|------|----------------|------|
| 1 | rag 和 graph rag 区别是什么？ | RAG101（TurnHint） | 显式主题词 |
| 2 | 详细点都讲解一下 | RAG101（代指近窗） | 指上一问，不漂 CAREER |
| 3 | 能举个课里的例子吗？ | RAG101（代指） | 仍指 RAG 讨论 |

**失败形态（旧 bug）**：第 2 轮变成 CAREER201，助教说「这门课是讲跳槽的、没有 RAG」。

## 三、重点：同一套代称 → 不同课程

> 学员全程几乎只说「那个 / 这个 / 详细点 / 继续 / 刚才的」，从不重复课名；  
> 系统必须根据**近窗里最近被激活的主题**（或话里的内容线索）决定指哪门课。

### 样例 9：纯代称乒乓（CAREER ↔ RAG）

助教答复用括号标「主题」，方便看代称落点。

```
① 学员：三年程序员，什么时候跳比较合适？
   助教：（讲跳槽时机…）                    → CAREER / Open
   【激活主题 = 跳槽/CAREER】

② 学员：详细点
   助教：（展开跳槽时机…）                  → CAREER
   【「详细点」= ①，仍是 CAREER】

③ 学员：对了我想问检索增强生成是啥
   助教：（讲 RAG 定义…）                   → RAG101
   【新主题激活 = RAG；不锁在 CAREER】

④ 学员：那个再展开说说
   助教：（展开 RAG…）                      → RAG101
   【「那个」= ③ 的 RAG，不是 ① 的跳槽】

⑤ 学员：继续
   助教：（继续 RAG 深讲…）                 → RAG101
   【「继续」跟当前激活主题 RAG】

⑥ 学员：那刚才跳槽那个呢？详细点
   助教：（回到跳槽展开…）                  → CAREER
   【「刚才跳槽那个」显式拨回 CAREER；若只说「那个」易歧义，见样例 10】

⑦ 学员：这个和上面检索那套怎么结合起来讲面试？
   助教：（职业表达 + 可引用 RAG 概念；主检索 CAREER 或 Open）
   【「这个」偏面试/跳槽；「上面检索」是线索回指 RAG，允许跨域组织】
```

| 代称原话 | 落点课 | 依据 |
|----------|--------|------|
| ② 详细点 | CAREER | 最近完整问是跳槽 |
| ④ 那个再展开 | RAG101 | 最近完整问是 RAG |
| ⑤ 继续 | RAG101 | 当前激活主题仍是 RAG |
| ⑥ 刚才跳槽那个 | CAREER | 话里带主题线索 |
| ⑦ 这个 + 上面检索 | 主 CAREER/Open，可旁引 RAG | 双线索 |

### 样例 10：歧义代称「那个」——靠近窗「最后激活主题」

同一句「那个呢？」，因插入话题不同而落点不同。

**10a — 最后激活是 RAG**

```
① 学员：跳槽节奏怎么规划？
   → CAREER 激活
② 学员：RAG 三大核心是什么？
   → RAG 激活（覆盖「当前主题」）
③ 学员：那个呢？再讲细点
   → 期望 RAG101
   （「那个」默认指当前激活主题 = ② RAG，不是 ① 跳槽）
```

**10b — 最后激活是 CAREER**

```
① 学员：Graph RAG 和普通 RAG 差别？
   → RAG 激活
② 学员：谈薪一般怎么开场？
   → CAREER 激活
③ 学员：那个呢？再讲细点
   → 期望 CAREER
   （当前激活 = ② 谈薪）
```

**10c — 学员用内容线索消歧（仍无课名）**

```
① …（RAG 已讲过）
② …（跳槽已讲过）
③ 学员：那个「图遍历」再来一句
   → RAG101（内容线索「图遍历」，不是课 id）
④ 学员：那个「第三年窗口」再展开
   → CAREER（内容线索「第三年窗口」）
```

**产品约定（写进实现）**：

1. 无内容线索的纯代称（那个 / 详细点 / 继续）→ 指 **当前激活主题**（通常 = 最近一轮完整问答的主题）。  
2. 带内容线索的代称（图遍历 / 谈薪开场 / 先查资料）→ 在近窗中匹配线索，**可跳过中间轮**指回更早的课。  
3. 实在解析不出 → **Open 全库**，不要猜错锁死。

### 样例 11：三轮纯代称，主题被学员「拨来拨去」

```
① 学员：什么是 embedding？
   助教：（向量表示…）                      → RAG101
   激活 = RAG

② 学员：详细点
   → RAG101（代称→①）

③ 学员：群面一般注意什么？
   助教：（群面技巧…）                      → CAREER201
   激活 = CAREER

④ 学员：详细点
   → CAREER（代称→③，同一句「详细点」已换课）

⑤ 学员：继续
   → CAREER（仍跟激活主题）

⑥ 学员：回到刚才那个向量的
   助教：（embedding…）                     → RAG101
   【「向量」= 内容线索，无课名】

⑦ 学员：详细点
   → RAG101（激活已拨回 RAG）

⑧ 学员：那个群面的补充两点就行
   → CAREER（「群面」线索）
```

**验收句**：②④⑦ 三句都是「详细点」，但期望课分别是 RAG → CAREER → RAG。

### 样例 12：只有代称 + 助教上一句里的词（学员不点名）

```
① 学员：检索的时候 rerank 有什么用？
   助教：……精排会把候选再排一次……          → RAG101

② 学员：这个再讲讲原理
   → RAG101（「这个」= 上句精排/rerank）

③ 学员：转头问：面试里怎么吹这个亮点？
   助教：……可以说你优化过检索链路……        → CAREER / Open
   激活偏求职表达

④ 学员：那这个怎么说更顺？
   → CAREER / Open（「这个」= ③ 的面试话术，不是 ① 的 rerank 公式）

⑤ 学员：公式那边再一口
   → RAG101（「公式」线索回指技术）
```

### 样例 8：连续自由跳（整段）

```
学员：最近想跳槽，三年 C++ 怎么规划？     → CAREER / Open
学员：对了，RAG 和 Graph RAG 区别说说     → RAG101
学员：详细点，尤其是检索机制               → RAG101
学员：那回到跳槽，面试怎么讲项目里的检索优化？ → CAREER / Open
学员：上面 Graph RAG 那个图遍历再讲一句   → RAG101
```

### 样例 13：长近窗里两个「那个」（必须靠线索）

```
①～④：交替讲过「知识库切块」和「跳槽窗口」
⑤ 学员：那个再讲一下
   → 歧义；若无线索 → 跟「当前激活主题」（④ 的主题）
⑥ 学员：不是，是切块那个
   → RAG101（「切块」线索纠偏）
⑦ 学员：对对，那个窗口也补两句
   → CAREER（「窗口」线索）
```
